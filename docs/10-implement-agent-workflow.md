# 멀티 에이전트 워크플로우 구현하기

[Microsoft Agent Framework(MAF)](https://aka.ms/agentframework)는 단일 에이전트 및 멀티 에이전트 앱을 손쉽게 만들 수 있는 에이전틱 AI 프레임워크입니다. 멀티 에이전트를 작동시키기 위해 사용하는 다양한 워크플로우가 있습니다. 이 세션에서는 MAF를 이용해 앞서 작성했던 급식 평가 루브릭을 바탕으로 멀티 에이전트 앱을 구현합니다.

## 직접 프롬프트 입력하기

1. Copilot app 왼쪽의 리포지토리 옆에 있는 "+" 버튼을 클릭해서 새 세션을 생성합니다.
1. 아래 프롬프트를 이용해 급식 평가에 알맞는 멀티 에이전트 워크플로우 패턴을 찾아냅니다.

    ```text
    Microsoft Agent Framework가 지원하는 멀티 에이전트 워크플로우 패턴에 대해 설명해 줘. 그리고, 각각의 워크플로우 패턴을 `EVALUATION_RUBRIC.md`에 있는 평가 항목에 적용시킨다면 어떤 장단점이 있을지, 그리고 최적의 워크플로우 패턴은 어떤 것일지도 설명해 줘.
    ```
1. 몇 번 프롬프트를 주고 받다가 결론 내린 멀티 에이전트 워크플로우 패턴을 이용해서 앱을 구현합니다. 아래와 같은 프롬프트를 적용합니다. 이 때 기존의 이슈를 `#`으로 호출할 수 있습니다.

    ```text
    xxx 방식의 멀티 에이전트 오케스트레이션 패턴을 이용해서 #xxx 이슈를 구현해 줘. 앱 구현이 끝난 후에는 이슈에 정의된 인수 조건에 맞춰 검토해 줘.
    ```

1. 만족할 때 까지 수정한 후, 오른쪽 위의 "Create PR" 버튼을 클릭해서 방금 작업한 내용을 바탕으로 PR을 생성합니다.
1. PR이 만들어졌고, 머지할 준비가 끝났습니다. "Ready to merge" 버튼을 클릭합니다.
1. 새 팝업 모달 창이 나타나면 "Merge pull request" 버튼을 클릭해서 방금 생성한 PR을 머지합니다.
1. 머지가 완료된 것을 확인합니다.
